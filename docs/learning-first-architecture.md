# Learning-first architecture · SeetheTruth

## 产品定位（2026-10-17）

SeetheTruth 是**Scratch 式大模型学习平台**，不是默认对接 GPU、Profiler 或大型模型计算的开发平台。首先让学生自己搭积木并理解数学依赖、张量轴语义、形状约束、位置编码、残差、注意力、训练/推理及 RL 的概念。**默认不运行张量乘法，也不要求预训练权重、GPU、PyTorch 或互联网**。

### 三层能力、各自独立的证据等级

| 层级 | 运行内容 | 必选？ | 证据等级与限制 |
| --- | --- | --- | --- |
| **① 原理推演（默认）** | 从用户选定的积木、连线和参数推断形状、输入输出依赖、数学变换、内部阶段及仍需验证的值域条件 | **是** | `declared_semantic_and_shape_contract_not_numerical_execution`：只证明教学合同内的形状与逻辑，不声称取得真实矩阵、梯度、性能或训练效果 |
| ② 小矩阵数值演示 | 用户明确切换后才分配微型 JS Float64 张量，展示局部数值、GQA/Mask 等教学算子与有限 FLOPs 理论项 | 可选 | 确定性示例，不能外推模型速度或收敛质量；不加载真实模型 |
| ③ 外接计算或真实模型观察 | 未来可接 PyTorch/HF、CPU/GPU、真实 checkpoint、训练流程或可视化已存档证据 | **未来可选插件** | 必须自带 provenance、算子语义、对应源码版本、数值或性能的测量来源，不从教学积木反向冒充真实执行 |

GPU Profiling 属于第三层的可选 **adapter**，不是课程核心运行要求，也不是本地工作台启动或验收的依赖。现有源码图谱、RuntimeTrace 和 Profiler 工具可继续保留为研究扩展，但不能挤占主产品的学习流程。

## 原理推演的具体合同

- 基于 `learning_lab.js` 的 45 个积木声明式目录，`concept_flow.js` 对全部 45 个建立显式形状转移及数学作用规则；不调用 `L.evaluate`、`BlockCatalog.execute` 或矩阵计算函数。
- 前向走 DAG 的拓扑顺序；连线缺失、维度不相容、GQA Head 配置等可从形状得出的错误照样会被拒绝。
- 对离散标签、Mask 是否二值、输入是否归一化、除零等**只能靠值判断**的条件，不制造“已经验证”结论：标明`未验证的数值前置条件`。这对学生理解“知道 shape”和“知道值”之间的区别非常重要。
- 保留 node.kind、用户参数、公式、课程设计意图、shape、shape 转移与命名内部阶段等少量教学数据；`values:null`、`flops:null`、`noNumericalExecution:true`，避免暗中执行大型矩阵。
- 概念推演中允许对单个 Linear 等表达超过微型矩阵上限的**抽象维度**，例如 [2048,4096] → [2048,7]，不分配 2048×4096 的 Float64 数组。当前画布的完整工程编辑仍继承微型模式参数边界；将大维度以符号作为图谱级参数属于后续单独改造。

## 外接执行的未来契约（设计，不是已实现功能）

建议后续以**独立 adapter 接口**连接执行后端，而不是直接让每个教学积木依赖 GPU：

1. 输入：教学图 IR/算子 stable ID、模型/后端身份、配置、可选张量维度样本；明示是否允许访问真实权重。
2. 输出：`provenance`（源码 commit、配置与运行 ID）、`axis_contracts`、`tensor_shapes`、可选 `sampled_values` 和 `operator_events`，并提供每项是否真实观测的标签。
3. 数值后端不必复刻完整图；可接微型基准、服务器端模型、已有 traces，或只提供符号形状，必须按缺失字段真实退化。
4. 性能/CUDA 只能在明确安装、授权且用户主动启用相应扩展时展示，绝不在默认教学模式模拟产生。
5. 若真实证据与教学共识冲突，优先分别显示差异和来源，不使用通用模块名称覆盖实际源码行为。

## 验收

- `node tests/concept_flow_contracts.js`：45 种定性合同逐一与原有数值引擎的形状对照，12 个课程 + 自由构建全覆盖；反例包括断线、Attention/GQA 维度冲突；额外校验大尺寸 shape 可在不创建矩阵的前提下推断。
- `python tests/browser_acceptance.py`：默认模式不出现数值热力图和 FLOPs；切换到小矩阵模式后，旧教学图的数值计算仍可正常显示。
- `python tests/browser_catalog_screenshots.py`：实际 Chromium 浏览器截图覆盖定性 GQA 内部阶段和原先的可选数值教学案例。
- CI 保留现有扩展工具的测试以防退化，但“想使用学习工具”并不意味着用户需要或应当拥有 GPU。
