# SeetheTruth · 第二轮发布整改：手机实验路径与证据来源

2026-11-13 · 基于已通过八条工作流的发布候选 `f19c716c951d743a8c45d7148d2d78260fd572e1`。本轮属于独立设计整改，不合并主分支、不改变许可证与发布身份。

## 学习工作台：让操作靠近当前对象

**观察**：390px 首屏以前同时展示撤销、缩放、LoRA、Loop、导出等互不相关的工具，首次用户在找到执行模式和运行按钮前必须越过整个计算画布。手机操作优先级改为：**选择当前图 → 推演或数值运行 → 查看当前步骤**。

- `learn.html` 的手机画布标题后提供「数值演示：开/关」「推演计算逻辑／运行小矩阵」「查看本步结果」；其操作直接复用原有 `studyMode` 的变更事件、`#run` 计算动作和 `run/step/selected` 状态。没有新的前向、自动微分或状态引擎。
- 修改执行模式立即清除旧计算证据；未成功运行前「查看本步结果」禁用。运行后选中实际源 `run.steps[step].id`，将焦点移动到已有的 `#inspectorTitle`，支持键盘和触控。
- 手机常用图操作保留缩放、适配、定位、检查。LoRA、Loop、布局整理、后端导出和本地工程文件放入同一 `details` 区域。桌面保留直接访问原控件，全部控件 ID 和行为不变。
- 「定位节点」仍使用既有缩放与节点位置，将当前选中节点在画布内居中并滚入视野。删除按钮增加具体节点 ID 的可访问名称，并说明可撤销。
- Android 教学工作台仍使用同一计算图与课程；没有引入文件导出。手机运行控制可换行，避免整组按钮被强制撑成单行横向滚动。

## 遥测页面：导入记录不等于独立证据

`telemetry.html` 的数据详情现在直接显示来源等级：

- `SYNTHETIC`：由程序生成的教学示意值，不是实际模型测量。
- `IMPORTED JSON`：本地导入文件经真实 `SeetheTruthUnifiedCore.inspectEvidence('telemetry','validate_import')` 校验；采集来源仍是文件中的自述，尚未独立复现。

模块时间、张量统计和热力图在前端直接展示时使用限定性陈述，保留现有单位、样本数、CPU/设备口径和缺失数据处理。没有改变原始校验器或数据、数值统计、绘图逻辑。

## 验收边界

`tests/sitewide_ui_contracts.js` 增加移动任务与数据来源标签的结构合同；`tests/browser_sitewide_ui_audit.py` 真实在 390px Chromium 执行手机快捷运行、模式切换后的旧证据撤销、查看结果后的可访问焦点、展开高级控件、定位节点，以及合成/导入遥测来源标记。

本地已运行 JS 语法检查、核心静态合同、页面 320/390/1440px HTML/CSS 预检。**本地 Chromium 对 127.0.0.1 的 HTTP 访问被环境策略阻止**；最终功能验收只能由精确新提交的 GitHub Actions Chromium CI 及其截图判定。正式 Android 真机、用户任务可理解性、授权与合并后的 Tag 仍需单独评估。

审查成功条件是：第一次移动操作能完成计算并看到对应本步公式/形状/数值；手动切换执行方式或编辑图会撤销旧证据；展开的高级功能可操作；导入的观测数据不会显示成已经独立复现的模型测量。

## 桌面小图的双轴适配（CI 回归修复）

第一轮完整 Chromium 运行在原 1600×1000 Mask Softmax 目录场景观察到 `mask` 节点底部 798.672px、视口底部 777.578px，超出约 21.1px。新增的工具分组改变了桌面画布可用高度；单独根据画布宽度计算缩放比例已不足以保证小教学图可见。现在对 8 个及以下节点的教学图同时约束横向、纵向拟合比例，保留大图的可读缩放与滚动。原节点完整可见断言保留，并新增首屏自动拟合和主动“适配”两种条件下的逐节点几何验收。需要在新提交 CI 中验证，不以算法源码检查代替布局验收。

## 320px 触控遮挡修复

真实 320px 首屏截图显示，右下角的固定「架构设计权衡」链接覆盖了画布内的积木。该操作属于次级研究导航，改放进已存在的「其他实验室」菜单；同一链接仍存在且可键盘/触控访问，无需创建新导航结构。新增浏览器回归验证没有绝对固定的该链接覆盖画布，并能从菜单到达相同目标。

## 显式适配与默认可读缩放的语义区分

第二轮完整 Chromium 在 20 节点的 MLA 教学图发现：默认可读缩放为 72%，点击「适配」后仍为 72%，未产生全图缩放。原因是两条操作复用了同一个最小缩放值。现在自动浏览仍保留 72% 下限，大图可滚动；**用户显式点击适配**允许缩小至 25% 以适应全部宽度，小型图继续同时考虑高度。原节点完整可见、以及明确适配应改变缩放的浏览器断言均保留。
