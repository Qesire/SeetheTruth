# SeetheTruth · Command Deck 视觉规范

## 设计方向

将模型研究工作台塑造成具有操作感的科幻指挥终端：深海军蓝金属结构、机械面板边框、青蓝状态读数、琥珀色关键动作，以及适合计算图的网格空间。参考《星际争霸 II》人类指挥界面的信息组织和材质层次，保留 SeetheTruth 自有名称、符号、图表与源代码机制。

## 视觉语法

| 元素 | 风格 | 学习作用 |
| --- | --- | --- |
| 计算画布 | 深蓝分区网格 | 保留数学积木和连线的视觉优先级 |
| 信息面板 | 金属分层背景、顶部高光和装甲切角 | 区分控制、观察和解释区域 |
| 当前节点 | 青色轮廓与局部光晕 | 追踪计算位置或当前事件 |
| 核心执行 | 琥珀色操作按钮 | 与普通导航分开 |
| 已核验证据 | 薄荷绿读数、邻近来源标注 | 呈现可回放的计算和状态观察 |
| 结构与来源 | 等宽字体、缩写状态标签 | 显示输入、版本和因果链 |

## 实施

共享 CSS 文件：command_deck.css。由静态发布策略 static_asset_policy.json 管理，并随 Android 教学包离线分发。统一作用于架构图谱、Learning Studio、课程首页、安卓入口和三个 DeepInfer 原生状态实验室。只改变视觉表达，不替代算术内核与状态回放。

尊重键盘焦点、触控点击区域、窄屏布局与 reduced-motion 偏好。所有边框、发光角标和网格均为原创 CSS，不加载外部字体或游戏贴图。

## 验收

- node tests/command_deck_contracts.js：页面覆盖、离线清单、代码出处。
- python tests/browser_command_deck.py：实际 Chromium 主题、手机溢出、初始化和截图。
- python tests/browser_state_learning_guide.py：真实原生 A/B 操作与状态证据。

风格一致性来自统一结构与交互反馈，视觉冲击力服务于计算机制的解释。
