严格的模型边界

CPU 和 GPU 各为单资源事件队列；只有合法依赖满足后才能执行。ZOS 允许将上轮 Sample 的 CPU 后处理放到下一轮 Forward 发起后，产生潜在重叠。

元数据修正按上一轮采样事件建立依赖，但这里没有实现 C++ Scheduler、CUDA Graph、真实 Token 接收、H2D/D2H 时间、设备并行流、EP/CP 或 KV 内存生命周期。
